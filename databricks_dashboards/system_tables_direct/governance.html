What this dashboard is for

One governance dashboard over system.access: broad grants, admin changes by hand, outbound requests a network policy blocked and workspace use, each on its own tab, with an Overview of their headline numbers and a tab showing the dashboard's own load from its query tags.

Databricks basics

TermWhat it means
System tablesRead-only tables Databricks fills for the whole account under the catalog system (system.billing, system.lakeflow, system.compute, system.access). The dashboards read them live; there are no tables of our own.
Audit logsystem.access.audit: one row per action someone took (log in, grant, change a group, ...), with who did it, when, in which workspace, the request and whether it succeeded. Databricks keeps it for 365 days.
Unity Catalog, grantUnity Catalog governs data: catalogs hold schemas, schemas hold tables. A grant gives a principal a privilege on one of them (SELECT, MODIFY, ALL PRIVILEGES, ...); a grant on a catalog or schema reaches everything inside it.
User, group, service principalA user is a person (an email). A group bundles users. A service principal is a non-human identity for automation (CI/CD, Terraform); in the audit log it appears as its application id, a UUID like 1b2c3d4e-....
account usersA built-in group holding every user of the account. Granting it something gives that to everyone.
Network policy, egressRules for which outside destinations serverless compute may reach. A refused request is written to system.access.outbound_network; in dry-run mode it is only logged, not blocked.
Query tagsKey-value labels set with SET QUERY_TAGS at the top of a query and stored with it in system.query.history (query_tags). Here: domain, cost_center, dashboard and tab.
Query, CTEA query is SQL. Each one here is a chain of named steps written WITH name AS (...), called CTEs; each step reads the ones before it, and one last SELECT gives the rows.

What it can miss

  • Only events still in the audit log (365 days).
  • outbound_network holds serverless egress only, and only where a network policy is set; no policy, no rows.
  • Dashboard load counts queries and run time, not $: the warehouse's bill covers every query it ran.
  • Revokes are left out; Admin changes shows them.
  • The object and grantee come from the event's request_params (securable_type, securable_full_name, changes); if Databricks changes that layout the table goes empty. Check with the query below.
  • Some system tables only hold workspaces in the same cloud region as the metastore; if a workspace is missing, check its region.

       ROUND(SUM(total_duration_ms) / 3600000, 2) AS hours
FROM system.query.history
WHERE query_tags['dashboard'] = 'governance' AND query_tags['tab'] IS NOT NULL
  AND statement_type <> 'SET' AND start_time >= current_date() - 30
GROUP BY 1 ORDER BY 2 DESC;

How to read a query

  • No snapshot. Each query reads the Databricks system tables directly, every time the dashboard opens or a filter changes.
  • Widgets share queries. Each widget reads one query and adds up its rows its own way (the Widgets table says how); widgets that read the same query always agree.
  • Each query reads like a recipe: named steps (WITH step AS (...), called CTEs), each building on the one before, then one final SELECT. A step named after a check (for example lakeflow_job_reliability) is a shared, tested check reused unchanged except for the dates; its own steps are listed under it.
  • Time Window: :time_range.min and :time_range.max are the dates picked in the Time Window filter (on Global Filters, or on the page). The end day counts in full.
  • Workspace and the other field filters need no SQL: Databricks keeps the rows whose column matches the pick.
  • $ is list price (usage x the SKU's list price), not the invoice.
  • Comments in the SQL (green, starting --) are added on this page only.

    2. Steps (CTEs), in order

    1. g: Broad grants: the Broad grants query, counted.
      Its SQL (49 lines)
      -- Governance overview: the headline number of each tab. Dates from the Time Window; inactive workspaces are today's view.
-- Broad grants: the Broad grants query, counted.
g AS (
  SELECT COALESCE(SUM(critical), 0) AS critical_grants, COUNT(*) AS grants FROM (
    -- Grants: every privilege granted in Unity Catalog, broad ones flagged. Dates from the Time Window.
    WITH ws AS (
      SELECT CAST(workspace_id AS STRING) AS workspace_id, workspace_name
      FROM system.access.workspaces_latest
    ),
    ev AS (
      SELECT event_id, event_time, CAST(workspace_id AS STRING) AS workspace_id,
             COALESCE(user_identity.email, user_identity.subject_name) AS actor,
             upper(request_params['securable_type']) AS object_type,
             request_params['securable_full_name'] AS object,
             request_params['changes'] AS changes
      FROM system.access.audit
      WHERE service_name = 'unityCatalog' AND action_name = 'updatePermissions'
        AND response.status_code = 200
        AND event_date >= CAST(:time_range.min AS DATE) AND event_date < date_add(:time_range.max, 1)
      QUALIFY ROW_NUMBER() OVER (PARTITION BY event_id ORDER BY event_time DESC) = 1
    ),
    per_grantee AS (
      SELECT ev.*, explode(from_json(changes, 'ARRAY<STRUCT<principal: STRING, add: ARRAY<STRING>, remove: ARRAY<STRING>>>')) AS c
      FROM ev
    ),
    granted AS (
      SELECT event_time, workspace_id, actor, object_type, object, c.principal AS grantee,
             upper(replace(p, ' ', '_')) AS privilege
      FROM per_grantee
      LATERAL VIEW explode(c.add) x AS p
    ),
    judged AS (
      SELECT g.*,
             g.privilege = 'ALL_PRIVILEGES' AND g.object_type IN ('CATALOG', 'SCHEMA', 'TABLE') AS all_privileges,
             lower(g.grantee) = 'account users' AS to_account_users
      FROM granted g
    )
    SELECT CAST(event_time AS STRING) AS granted_at, CAST(event_time AS DATE) AS day,
           CASE WHEN j.workspace_id = '0' THEN 'Account' ELSE COALESCE(ws.workspace_name, j.workspace_id) END AS workspace, object_type, object, privilege, grantee, actor,
           CASE WHEN actor RLIKE '^[0-9a-fA-F]{8}-[0-9a-fA-F]{4}-[0-9a-fA-F]{4}-[0-9a-fA-F]{4}-[0-9a-fA-F]{12}$' THEN 'Service principal' WHEN actor LIKE '%@%' THEN 'User' WHEN actor IS NULL THEN 'Unknown' ELSE 'Other (system)' END AS actor_type, 1 AS grants,
           CASE WHEN all_privileges AND to_account_users THEN 'All privileges to account users'
                WHEN all_privileges THEN 'All privileges'
                WHEN to_account_users THEN 'To account users' ELSE 'Not broad' END AS why,
           CASE WHEN all_privileges OR to_account_users THEN 1 ELSE 0 END AS critical
    FROM judged j
    LEFT JOIN ws ON ws.workspace_id = j.workspace_id
    ORDER BY critical DESC, event_time DESC
  ) x
)
    2. a: Admin changes: the Admin changes query, counted; by people = not a service principal.
      Its SQL (71 lines)
      -- Admin changes: the Admin changes query, counted; by people = not a service principal.
a AS (
  SELECT COALESCE(SUM(by_user), 0) AS manual_changes, COUNT(*) AS admin_changes FROM (
    -- Admin changes: who changed groups, roles, grants and settings. Dates from the Time Window.
    WITH ws AS (
      SELECT CAST(workspace_id AS STRING) AS workspace_id, workspace_name
      FROM system.access.workspaces_latest
    ),
    actions AS (
      SELECT * FROM VALUES ('accounts', 'addPrincipalToGroup', 'Group membership'),
             ('accounts', 'addPrincipalsToGroup', 'Group membership'),
             ('accounts', 'removePrincipalFromGroup', 'Group membership'),
             ('accounts', 'removePrincipalsFromGroup', 'Group membership'),
             ('accounts', 'createGroup', 'Groups'),
             ('accounts', 'removeGroup', 'Groups'),
             ('accounts', 'updateGroup', 'Groups'),
             ('accounts', 'setAdmin', 'Admin role'),
             ('accounts', 'removeAdmin', 'Admin role'),
             ('accounts', 'setAccountAdmin', 'Admin role'),
             ('accounts', 'removeAccountAdmin', 'Admin role'),
             ('accountsManager', 'changeAccountOwner', 'Admin role'),
             ('workspace', 'updateRoleAssignment', 'Workspace access'),
             ('workspace', 'addPermissionAssignment', 'Workspace access'),
             ('workspace', 'updatePermissionAssignment', 'Workspace access'),
             ('workspace', 'deletePermissionAssignment', 'Workspace access'),
             ('unityCatalog', 'updatePermissions', 'Grants (Unity Catalog)'),
             ('unityCatalog', 'updateSharePermissions', 'Grants (Unity Catalog)'),
             ('accounts', 'changeDatabricksSqlAcl', 'Permissions (ACL)'),
             ('accounts', 'changeDatabricksWorkspaceAcl', 'Permissions (ACL)'),
             ('accounts', 'changeDatabricksWorkspaceDirectoryAcl', 'Permissions (ACL)'),
             ('accounts', 'changeServicePrincipalAcls', 'Permissions (ACL)'),
             ('workspace', 'changeWorkspaceAcl', 'Permissions (ACL)'),
             ('accountsAccessControl', 'updateRuleSet', 'Permissions (ACL)'),
             ('clusterPolicies', 'create', 'Cluster policies'),
             ('clusterPolicies', 'edit', 'Cluster policies'),
             ('clusterPolicies', 'delete', 'Cluster policies'),
             ('clusterPolicies', 'changeClusterPolicyAcl', 'Cluster policies'),
             ('workspace', 'workspaceConfEdit', 'Settings'),
             ('workspace', 'setSetting', 'Settings'),
             ('workspace', 'deleteSetting', 'Settings'),
             ('accounts', 'setSetting', 'Settings'),
             ('accounts', 'deleteSetting', 'Settings')
        AS a(service_name, action_name, category)
    ),
    ev AS (
      SELECT e.event_time, CAST(e.workspace_id AS STRING) AS workspace_id, e.service_name, e.action_name, a.category,
             COALESCE(e.user_identity.email, e.user_identity.subject_name) AS actor,
             e.response.status_code AS status_code,
             -- what was changed: the object, or user -> group; the keys differ by action
             COALESCE(e.request_params['securable_full_name'],
                      CASE WHEN e.request_params['targetGroupName'] IS NOT NULL
                           THEN concat(COALESCE(e.request_params['targetUserName'], e.request_params['targetUserId'], '?'), ' -> ',
                                       e.request_params['targetGroupName']) END,
                      e.request_params['targetUserName'], e.request_params['targetUserId'], e.request_params['groupName'], e.request_params['name'],
                      e.request_params['principal'], e.request_params['resourceId'], e.request_params['policy_id'], e.request_params['workspaceConfKeys'], '-') AS target,
             e.request_params['changes'] AS changes
      FROM system.access.audit e
      JOIN actions a ON a.service_name = e.service_name AND a.action_name = e.action_name
      WHERE e.event_date >= CAST(:time_range.min AS DATE) AND e.event_date < date_add(:time_range.max, 1)
      QUALIFY ROW_NUMBER() OVER (PARTITION BY e.event_id ORDER BY e.event_time DESC) = 1
    )
    SELECT CAST(event_time AS STRING) AS changed_at, CAST(event_time AS DATE) AS day,
           CASE WHEN e.workspace_id = '0' THEN 'Account' ELSE COALESCE(ws.workspace_name, e.workspace_id) END AS workspace, category, action_name AS action, target,
           left(changes, 300) AS change, actor, CASE WHEN actor RLIKE '^[0-9a-fA-F]{8}-[0-9a-fA-F]{4}-[0-9a-fA-F]{4}-[0-9a-fA-F]{4}-[0-9a-fA-F]{12}$' THEN 'Service principal' WHEN actor LIKE '%@%' THEN 'User' WHEN actor IS NULL THEN 'Unknown' ELSE 'Other (system)' END AS actor_type, 1 AS changes_count,
           CASE WHEN status_code = 200 THEN 'Done' WHEN status_code IS NULL THEN 'Unknown' ELSE 'Failed' END AS outcome,
           CASE WHEN actor LIKE '%@%' THEN 1 ELSE 0 END AS by_user
    FROM ev e
    LEFT JOIN ws ON ws.workspace_id = e.workspace_id
    ORDER BY event_time DESC
  ) x
)
    3. n: Network: the Network query, blocked and dry-run requests.
      Its SQL (35 lines)
      -- Network: the Network query, blocked and dry-run requests.
n AS (
  SELECT COALESCE(SUM(blocked), 0) AS blocked_requests, COALESCE(SUM(dry_run), 0) AS dry_run_requests
  FROM (
    -- Outbound network: requests a network policy denied, per day and destination. Dates from the Time Window.
    WITH ws AS (
      SELECT CAST(workspace_id AS STRING) AS workspace_id, workspace_name
      FROM system.access.workspaces_latest
    ),
    ev AS (
      SELECT CAST(workspace_id AS STRING) AS workspace_id, event_time, network_source_type, destination_type,
             destination, upper(access_type) AS access_type,
             COALESCE(storage_event.rejection_reason, CAST(dns_event.rcode AS STRING)) AS reason
      FROM system.access.outbound_network
      WHERE event_time >= CAST(:time_range.min AS DATE) AND event_time < date_add(:time_range.max, 1)
    ),
    judged AS (
      SELECT ev.*,
             -- a dry-run denial is logged, not blocked: a policy being tried out
             CASE WHEN access_type = 'DRY_RUN_DENIAL' THEN 'Dry run'
                  WHEN access_type LIKE 'ALLOW%' THEN 'Allowed' ELSE 'Blocked' END AS outcome
      FROM ev
    )
    SELECT CAST(event_time AS DATE) AS day, COALESCE(ws.workspace_name, CAST(j.workspace_id AS STRING), 'Account-level') AS workspace, network_source_type AS source,
           destination_type, destination, access_type, outcome, COALESCE(reason, '-') AS reason,
           COUNT(*) AS events,
           SUM(CASE WHEN outcome = 'Blocked' THEN 1 ELSE 0 END) AS blocked,
           SUM(CASE WHEN outcome = 'Dry run' THEN 1 ELSE 0 END) AS dry_run,
           CAST(MIN(event_time) AS STRING) AS first_seen, CAST(MAX(event_time) AS STRING) AS last_seen
    FROM judged j
    LEFT JOIN ws ON ws.workspace_id = j.workspace_id
    GROUP BY ALL
    ORDER BY blocked DESC, events DESC
  ) x
)
    4. w: Workspace usage: the inactive-workspace query (90+ days without activity).
      Its SQL (39 lines)
      -- Workspace usage: the inactive-workspace query (90+ days without activity).
w AS (
  SELECT COALESCE(SUM(inactive), 0) AS inactive_workspaces, COUNT(*) AS workspaces FROM (
    -- Workspace activity: last audit event, inactive after 90 days. Today's view; no dates.
    WITH ws AS (
      SELECT CAST(workspace_id AS STRING) AS workspace_id, workspace_name
      FROM system.access.workspaces_latest
    ),
    classes AS (
      -- no classes set: every workspace reads Not classified
      SELECT CAST(NULL AS STRING) AS workspace_class, CAST(NULL AS STRING) AS name_pattern, 0 AS priority
      WHERE FALSE
    ),
    ws_class AS (
      SELECT w.workspace_id, w.workspace_name,
             COALESCE(MIN_BY(c.workspace_class, c.priority), 'Not classified') AS workspace_class
      FROM ws w LEFT JOIN classes c ON lower(w.workspace_name) LIKE c.name_pattern
      GROUP BY w.workspace_id, w.workspace_name
    ),
    seen AS (
      SELECT CAST(workspace_id AS STRING) AS workspace_id, MAX(event_date) AS last_activity

    Shows: Every query of this dashboard in the window, found by its query tags (dashboard = governance), per tab, day, identity and warehouse: count, failures, run time and data read. Used by: The Dashboard load page and the Overview tile.

    Why it is built this way: A dashboard's query text reads <REDACTED> in the query history, so only its tags tell its queries apart. Counting them per tab shows what the dashboard itself costs to run.

    -- Dashboard load: this dashboard's own queries, per tab, from their query tags. Dates from the Time Window.
-- Warehouse id to name: the latest row per warehouse.
WITH wh AS (
  SELECT CAST(warehouse_id AS STRING) AS warehouse_id, warehouse_name FROM system.compute.warehouses
  QUALIFY ROW_NUMBER() OVER (PARTITION BY warehouse_id ORDER BY change_time DESC) = 1
),
-- This dashboard's queries in the window: query_tags dashboard = governance, with a tab.
q AS (
  SELECT query_tags['tab'] AS tab, CAST(start_time AS DATE) AS day, executed_by,
         CAST(compute.warehouse_id AS STRING) AS warehouse_id, execution_status,
         COALESCE(total_duration_ms, 0) AS duration_ms, COALESCE(read_bytes, 0) AS read_bytes
  FROM system.query.history
  -- the SET QUERY_TAGS statements are not the dashboard's work; on a reused session they carry a tab
  WHERE query_tags['dashboard'] = 'governance' AND query_tags['tab'] IS NOT NULL
    AND upper(COALESCE(statement_type, '')) <> 'SET'
    AND start_time >= CAST(:time_range.min AS DATE) AND start_time < date_add(:time_range.max, 1)
)
-- Final SELECT: the rows the widgets read.
SELECT q.tab, q.day, q.executed_by AS run_as, COALESCE(wh.warehouse_name, q.warehouse_id) AS warehouse,
       COUNT(*) AS queries,
       SUM(CASE WHEN q.execution_status = 'FAILED' THEN 1 ELSE 0 END) AS failed,
       ROUND(SUM(q.duration_ms) / 3600000, 3) AS hours,
       ROUND(SUM(q.read_bytes) / 1e9, 2) AS gb_read
FROM q
LEFT JOIN wh ON wh.warehouse_id = q.warehouse_id
GROUP BY ALL
ORDER BY q.day DESC, hours DESC

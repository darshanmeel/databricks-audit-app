How to read a query

  • Two steps. The notebook Lakehouse Health 00 - Snapshot reads the Databricks system tables once and saves one small table per check in databricks_audit_dashboard. The dashboard queries below read only those saved tables, so they are fast and never touch the system tables.
  • Each query reads like a recipe: the tables it starts from, then a chain of named steps (WITH step AS (...), called CTEs, each building on the one before), then one final SELECT that gives the widget its rows.
  • Name lookup: ids are turned into names by LEFT JOINs to the dim_* tables. A LEFT JOIN keeps the row even when no name is found; it then shows its id.
  • Workspace filter: :workspace is what is picked on Global Filters; array_contains(:workspace, ...) keeps rows of the picked workspaces, or all of them.
  • $: list price, less the discount set when the dashboards were built: (1.0 - 0.0) means no discount.
  • $50 floor: a resource counts as waste only at $50 per 30 days or more.
  • Comments in the SQL (green, starting --) are added on this page only. Long name lookups are broken over lines; nothing else differs from the dashboard.

Possible waste · KPI

Shows: Adds up possible waste over the 5 priced checks after the $50 floor. Why: The headline number: what could be saved.

1. Tables it reads

  • compute_idle_node_ratio: One row per classic cluster: how much of its node time had almost no CPU in use, and that idle time's $. Built by the notebook from system.billing.list_prices, system.billing.usage, system.compute.node_timeline.
  • compute_serving_endpoint_cost_status: One row per serving endpoint: its cost, and whether it billed with zero requests. Built by the notebook from system.access.workspaces_latest, system.billing.list_prices, system.billing.usage, system.serving.endpoint_usage, system.serving.served_entities.
  • compute_warehouse_idle_minutes: One row per SQL warehouse: minutes running, busy and idle in the window, the $ of idle time, its auto-stop setting, and the replay columns autostop_N_* (idle minutes and cold starts had auto-stop been N minutes). Built by the notebook from system.billing.list_prices, system.billing.usage, system.compute.warehouse_events, system.compute.warehouses, system.query.history.
  • cost_failed_statement_waste: One row per warehouse: $ spent on SQL statements that failed. Built by the notebook from system.billing.attributed_usage, system.billing.list_prices, system.billing.usage, system.query.history.
  • dim_cluster: Cluster id -> name. Built by the notebook from system.billing.usage, system.compute.clusters.
  • dim_job: Job id -> name. Built by the notebook from system.lakeflow.jobs.
  • dim_warehouse: Warehouse id -> name. Built by the notebook from system.compute.warehouses.
  • dim_workspace: Workspace id -> name. Built by the notebook from system.access.workspaces_latest, system.billing.usage, system.compute.clusters, system.compute.instance_pools, system.compute.warehouses, system.lakeflow.job_run_timeline, system.lakeflow.jobs, system.lakeflow.pipelines, system.query.history, system.serving.served_entities.
  • lakeflow_failed_jobs_wasted_dbus: One row per job: DBUs and $ spent on runs that failed. Built by the notebook from system.billing.list_prices, system.billing.usage, system.lakeflow.job_run_timeline.

2. Steps (CTEs), in order

  1. src: Stack the 5 priced waste checks into one list: one row per flagged resource, with its source, status and possible-waste $ (list price less your discount).
  2. eff: Apply the $50-per-30-days floor: a resource under it is treated as OK, so small amounts never count.
  3. named_all: Same rows with the workspace name added (kept for other widgets; this one may not use it).
  4. flagged: Keep only resources still Critical or Warn after the floor, with more than $0 of waste.
  5. named: Turn ids into names: workspace, and warehouse / cluster / job / endpoint by kind. LEFT JOINs, so a resource with no name row still shows by its id.
  6. named_ws: Copy workspace_name into ws_name, the column the Workspace filter reads.

3. Final query

Sums wasted $ over the flagged resources in the picked workspaces and counts them. Returns value ($), target ("N resources flagged").

SET QUERY_TAGS['cost_center'] = 'lakehouse_health';
SET QUERY_TAGS['domain'] = 'lakehouse_health';
SET QUERY_TAGS['dashboard'] = 'lakehouse_health_07_waste_savings';
SET QUERY_TAGS['tab'] = 'priced';
-- Stack the 5 priced waste checks into one list: one row per flagged resource, with its source, status and possible-waste $ (list price less your discount).
WITH src AS (
  SELECT 'Warehouse idle time' AS source_label, workspace_id, warehouse_id AS entity_id, 'warehouse' AS entity_kind,
         status, ROUND(est_wasted_usd_list * (1.0 - 0.0), 2) AS wasted, est_wasted_usd_list AS floor_value, window_days,
         (CASE WHEN window_days > 0 THEN 50 * window_days / 30.0 ELSE 50 END) AS floor_min
  FROM databricks_audit_dashboard.compute_warehouse_idle_minutes
  UNION ALL
  SELECT 'Idle cluster nodes', dc.workspace_id, w.cluster_id, 'cluster',
         w.status, ROUND(w.est_wasted_usd_list * (1.0 - 0.0), 2), w.est_wasted_usd_list, w.window_days,
         (CASE WHEN w.window_days > 0 THEN 50 * w.window_days / 30.0 ELSE 50 END)
  FROM databricks_audit_dashboard.compute_idle_node_ratio w
  LEFT JOIN databricks_audit_dashboard.dim_cluster dc ON dc.cluster_id = w.cluster_id
  UNION ALL
  SELECT 'Compute burned on failed runs', workspace_id, job_id, 'job',
         status, ROUND(est_wasted_usd_list * (1.0 - 0.0), 2), CAST(NULL AS DOUBLE), window_days, CAST(NULL AS DOUBLE)
  FROM databricks_audit_dashboard.lakeflow_failed_jobs_wasted_dbus
  UNION ALL
  SELECT 'Compute burned on failed statements', workspace_id, warehouse_id, 'warehouse',
         status, ROUND(est_wasted_usd_list * (1.0 - 0.0), 2), est_wasted_usd_list, window_days,
         (CASE WHEN window_days > 0 THEN 50 * window_days / 30.0 ELSE 50 END)
  FROM databricks_audit_dashboard.cost_failed_statement_waste
  UNION ALL
  SELECT 'Endpoints billed with no requests', workspace_id, endpoint_id, 'endpoint',
         status, ROUND(est_wasted_usd_list * (1.0 - 0.0), 2), est_usd_list, window_days,
         (CASE WHEN window_days > 0 THEN 50 * window_days / 30.0 ELSE 50 END)
  FROM databricks_audit_dashboard.compute_serving_endpoint_cost_status
),
-- Apply the $50-per-30-days floor: a resource under it is treated as OK, so small amounts never count.
eff AS (
  SELECT *,
         CASE WHEN status IN ('CRITICAL', 'WARN') AND floor_value < floor_min
              THEN 'OK' ELSE status END AS eff_status
  FROM src
),
-- Same rows with the workspace name added (kept for other widgets; this one may not use it).
named_all AS (
  SELECT e.*, COALESCE(ws.name, e.workspace_id, 'Account-level') AS workspace_name
  FROM eff e
  LEFT JOIN databricks_audit_dashboard.dim_workspace ws ON ws.workspace_id = e.workspace_id
),
-- Keep only resources still Critical or Warn after the floor, with more than $0 of waste.
flagged AS (
  SELECT source_label, workspace_id, entity_id, entity_kind, wasted
  FROM eff
  WHERE eff_status IN ('CRITICAL', 'WARN') AND wasted > 0
),
-- Turn ids into names: workspace, and warehouse / cluster / job / endpoint by kind. LEFT JOINs, so a resource with no name row still shows by its id.
named AS (
  SELECT f.source_label, f.entity_kind, f.wasted,
         COALESCE(ws.name, f.workspace_id, 'Account-level') AS workspace_name,
         COALESCE(dw.warehouse_name, dc.cluster_name, dj.name, ep.endpoint_name, f.entity_id) AS resource_name
  FROM flagged f
  LEFT JOIN databricks_audit_dashboard.dim_workspace ws ON ws.workspace_id = f.workspace_id
  LEFT JOIN databricks_audit_dashboard.dim_warehouse dw ON f.entity_kind = 'warehouse' AND dw.warehouse_id = f.entity_id
  LEFT JOIN databricks_audit_dashboard.dim_cluster dc ON f.entity_kind = 'cluster' AND dc.cluster_id = f.entity_id
  LEFT JOIN databricks_audit_dashboard.dim_job dj ON f.entity_kind = 'job' AND dj.workspace_id = f.workspace_id AND dj.job_id = f.entity_id
  LEFT JOIN databricks_audit_dashboard.compute_serving_endpoint_cost_status ep
    ON f.entity_kind = 'endpoint' AND ep.workspace_id = f.workspace_id AND ep.endpoint_id = f.entity_id
)
,
-- Copy workspace_name into ws_name, the column the Workspace filter reads.
named_ws AS (
  SELECT *, workspace_name AS ws_name FROM named
)
-- Final SELECT: the rows this widget reads.
SELECT ROUND(COALESCE(SUM(wasted), 0), 0) AS value,
       concat(CAST(count(*) AS STRING), ' resources flagged') AS target
FROM named_ws
-- Workspace filter: keep rows whose workspace is picked in Global Filters, or all when 'all' is picked.
WHERE (array_contains(:workspace, COALESCE(ws_name, '')) OR array_contains(:workspace, 'all'))

  FROM eff

WITH w AS (
  -- Name lookup: the check's table with names joined from the dim tables (workspace, warehouse, ...). nm_* = name, n_* = "name (id)", lbl_* = "name · workspace", ws_name = workspace for the filter.
  SELECT * FROM (SELECT t.*, COALESCE(d_workspace.n, CAST(t.`workspace_id` AS STRING)) AS nm_workspace, COALESCE(concat(d_workspace.n, ' (', CAST(t.`workspace_id` AS STRING), ')'), CAST(t.`workspace_id` AS STRING)) AS n_workspace, COALESCE(d_warehouse.n, CAST(t.`warehouse_id` AS STRING)) AS nm_warehouse, COALESCE(concat(d_warehouse.n, ' (', CAST(t.`warehouse_id` AS STRING), ')'), CAST(t.`warehouse_id` AS STRING)) AS n_warehouse, COALESCE(d_workspace.n, CAST(t.`workspace_id` AS STRING)) AS ws_name, CASE WHEN COALESCE(d_workspace.n, CAST(t.`workspace_id` AS STRING)) IS NULL THEN COALESCE(d_warehouse.n, CAST(t.`warehouse_id` AS STRING)) ELSE concat(COALESCE(d_warehouse.n, CAST(t.`warehouse_id` AS STRING)), ' · ', COALESCE(d_workspace.n, CAST(t.`workspace_id` AS STRING))) END AS lbl_warehouse

      LEFT JOIN (SELECT CAST(workspace_id AS STRING) AS workspace_id, max(name) AS n FROM databricks_audit_dashboard.dim_workspace GROUP BY CAST(workspace_id AS STRING)) d_workspace ON d_workspace.workspace_id = CAST(t.`workspace_id` AS STRING)
      LEFT JOIN (SELECT CAST(workspace_id AS STRING) AS workspace_id, CAST(warehouse_id AS STRING) AS warehouse_id, max(warehouse_name) AS n FROM databricks_audit_dashboard.dim_warehouse GROUP BY CAST(workspace_id AS STRING), CAST(warehouse_id AS STRING)) d_warehouse ON d_warehouse.workspace_id = CAST(t.`workspace_id` AS STRING) AND d_warehouse.warehouse_id = CAST(t.`warehouse_id` AS STRING))
  -- Workspace filter: keep rows whose workspace is picked in Global Filters, or all when 'all' is picked.
  WHERE (array_contains(:workspace, COALESCE(ws_name, '')) OR array_contains(:workspace, 'all')) AND not_assessed_reason IS NULL AND autostop_now_idle_minutes IS NOT NULL
    AND usd_per_cluster_minute IS NOT NULL AND auto_stop_minutes IS NOT NULL
),
-- The auto-stop settings to try, in minutes.
opt AS (SELECT * FROM (VALUES (1), (2), (5), (10), (30)) AS o(minutes)),
-- One row per warehouse and setting it could take: serverless from 1 min, pro and classic from 10, only settings shorter than today's. Picks that setting's replayed idle minutes and cold starts.
replay AS (
  SELECT w.*, o.minutes AS setting,
         CASE o.minutes WHEN 1 THEN autostop_1_idle_minutes WHEN 2 THEN autostop_2_idle_minutes
                        WHEN 5 THEN autostop_5_idle_minutes WHEN 10 THEN autostop_10_idle_minutes
                        ELSE autostop_30_idle_minutes END AS at_idle_minutes,
         CASE o.minutes WHEN 1 THEN autostop_1_cold_starts WHEN 2 THEN autostop_2_cold_starts
                        WHEN 5 THEN autostop_5_cold_starts WHEN 10 THEN autostop_10_cold_starts
                        ELSE autostop_30_cold_starts END AS at_cold_starts
  FROM w CROSS JOIN opt o
  WHERE (w.warehouse_kind = 'serverless' OR o.minutes >= 10)
    AND (w.auto_stop_minutes = 0 OR o.minutes < w.auto_stop_minutes)
),
-- Per warehouse and setting: $ saved, idle hours saved and extra cold starts versus today. The label is zero-padded ("05 min") so the chart sorts 1, 2, 5, 10, 30.
whatif AS (
  SELECT *, lpad(CAST(setting AS STRING), 2, '0') || ' min' AS setting_label,
         GREATEST(autostop_now_idle_minutes - at_idle_minutes, 0) * usd_per_cluster_minute * (1.0 - 0.0) AS saving_usd,
         GREATEST(autostop_now_idle_minutes - at_idle_minutes, 0) / 60.0 AS saved_hours,
         GREATEST(COALESCE(at_cold_starts, 0) - COALESCE(autostop_now_cold_starts, 0), 0) AS extra_starts
  FROM replay
  WHERE at_idle_minutes IS NOT NULL
)

       concat('+', CAST(COALESCE(SUM(extra_starts), 0) AS STRING), ' cold starts, ',
              CAST(count(*) AS STRING), ' warehouses') AS target
FROM whatif
WHERE warehouse_kind = 'serverless' AND setting = 1
